# CLAUDE.md — qviqa_bot

Инструкции для Claude Code (и любого агента) в этой репе.

## Обязательная инженерная политика — `.clauderc`

Файл [`.clauderc`](./.clauderc) содержит 99 жёстких, безкомпромиссных правил
проекта (архитектура, code review, тестирование/coverage 95%+, безопасность,
производительность, инженерные процессы). **Это не рекомендации — это
обязательные требования к любому изменению кода в этом репозитории.**
Прочитай `.clauderc` в начале любой сессии, где предстоит писать, ревьюить
или мержить код, и следуй ему как части системного промпта.

Главный закон файла (правило 99): код, не покрытый тестами на 95%+, с
архитектурными слепыми зонами или расходящийся с ТЗ — не имеет права
находиться в продакшене.

## Безопасность: секреты в истории git

Исходный коммит `6b0957a` («Add files via upload») на `main` содержит
файлы-экспорты BAS (`настройки 15.11.22.xml`, `messages*.html`) с **живыми
секретами в открытом виде**: токен Telegram-бота, логин/пароль SOCKS5-прокси,
секретный ключ QIWI P2P, токен freelancehunt.com, пароль superlance.pro,
URL Google Apps Script, токен webhook.site. Эти файлы не используются
портированным бекендом и не должны присутствовать в репозитории.

**Решение владельца репозитория (2026-07-30): git-историю не переписывать.**
Секреты остаются доступны через `git log`/GitHub у коммита `6b0957a` и его
потомков. Вместо этого владелец отзывает сами секреты у провайдеров —
это единственное, что реально закрывает утечку (переписывание истории не
отменяет уже случившуюся публикацию). Пошаговая инструкция со ссылками —
[`SECRETS_REVOCATION.md`](./SECRETS_REVOCATION.md). Если решение изменится —
`git filter-repo` для полной зачистки истории уже проверен в этой сессии.
